Importar produtos por texto

Uma linha por produto: QUANTIDADE NOME DO PRODUTO VALOR (a quantidade é opcional, padrão 1). Os produtos são criados sem custo (R$ 0,00) e já entram no estoque deste evento. Se já existir um produto com o mesmo nome, um novo é criado mesmo assim.

Importar CSV do evento anterior

Use o arquivo gerado em Eventos → Gerar CSV p/ novo evento. Colunas (separador ;): produtoId ; produtoNome ; corId ; corNome ; quantidade ; valor. Cada linha vira estoque deste evento, ligada ao produto existente pelo ID (ou pelo nome, se o ID não bater). Ao salvar, a Qtd é dada baixa do estoque do produto.
